# fuunshi - Portfolio

Modern, sleek, hacker-style portfolio website showcasing penetration testing expertise, security research, and full stack development background.

## Features

- **Minimalist Hacker Aesthetic**: Dark terminal-inspired design with neon green/cyan accents
- **Professional Showcase**: Highlights penetration testing skills, vulnerability exploitation, and security research
- **Platform Links**: Direct links to TryHackMe, Hack The Box profiles, and technical blog
- **Responsive Design**: Fully responsive layout for all devices
- **Smooth Animations**: Subtle glitch effects and smooth scroll animations

## Tech Stack

- Pure HTML5, CSS3, and Vanilla JavaScript
- No dependencies or frameworks
- Terminal-inspired UI with custom CSS
- Optimized for performance and accessibility

## Sections

1. **Hero**: Bold introduction with glitch effect
2. **About**: Terminal-style about section
3. **Expertise**: Skills grid highlighting key competencies
4. **Labs & Write-ups**: Links to TryHackMe, Hack The Box, and blog
5. **Contact**: Get in touch section with terminal aesthetic

## Deployment

Simply deploy the files to any static hosting service:
- GitHub Pages
- Netlify
- Vercel
- Any static web server
